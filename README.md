# MindLift (beta)

A simple daily learning app: one curiosity question a day in English and French, a short daily article, and free recorded narration (voices: Ava and Leo).

## Open the app
When this repository is published with GitHub Pages, the app is available at the Pages address shown in **Settings → Pages**. The app loads its lessons from separate files, so it needs to be opened from a web address (GitHub Pages or any web server) rather than by double-clicking `index.html`.

## What's inside
- `index.html` — the page that starts the app
- `css/app.css` — the design
- `js/app.js` — how the app works
- `data/` — the 60 daily lessons with their sources, the daily articles, and narration timings
- `img/` — lesson covers and article images
- `audio/` — narration for every lesson and article (Ava in English and French, Leo in English), voice samples and background music
