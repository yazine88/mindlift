# MindLift (beta)

A simple daily learning app: one curiosity question a day in English and French, a short daily article, and free recorded narration (voices: Ava and Leo).

## Open the app
Open `index.html` in any web browser. When this repository is published with GitHub Pages, the app is available at the Pages address shown in **Settings → Pages**.

## What's inside
- `index.html` — the whole app (design, lessons, articles)
- `audio/` — narration for every lesson and article, voice samples and background music
